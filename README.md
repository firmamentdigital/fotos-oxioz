# fotos-oxioz

Fotos de produto da **OxiOz** usadas pela IA de atendimento (Zoe) no n8n.

O nó `HTTP Request` (Evolution `sendMedia`) consome a URL bruta destes arquivos.
Repositório **público de propósito**: o `raw.githubusercontent.com` só serve arquivo
sem autenticação em repo público, e a Evolution baixa a mídia anonimamente.

⚠️ Só material de divulgação de produto entra aqui. Nada de credencial, dado de
cliente ou documento interno.

| Arquivo | Produto |
|---|---|
| `gerador-nevoa-ozonizada.jpeg` | Gerador de Névoa Ozonizada (lançamento, 08/2026) |

As demais fotos do catálogo seguem no repo do cliente
`fabriciofaquim72-cloud/fotos-oxioz` (temos só leitura lá).
